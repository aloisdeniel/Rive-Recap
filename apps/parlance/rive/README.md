# Parlance — 2026 recap (Rive)

A ten-scene, data-bound Wrapped-style recap for the fictional language-practice app **Parlance**, authored as RML for the Rive CLI (1.6.0). Pure RML: there are **no Luau scripts**, so the unsigned `.riv` from `--once` has nothing that needs signing.

| | |
|---|---|
| Source of truth | `tools/generate.py` (+ `tools/rml.py`) generates `scene.rml`, `components.rml` and `data.rml`. Edit the generator, then run `python3 tools/generate.py`. The RML can also be edited directly, but the next generator run overwrites it. |
| Runtime file | `build/parlance-recap.riv` (1.98 MB, built with `rive . --once`; still script-free) |
| Editor file | `build/parlance-recap.rev` was **not produced**: `rive . --once --rev=build/parlance-recap.rev` returns `Not logged in`. Run `rive login`, then that same command. |
| Fixtures | `fixtures/sample.json` (the brief's fixture), `fixtures/zero-user.json`, `fixtures/extreme.json` (huge values, a long name, copy at least 40% longer) |
| Captures | `captures/` holds settled scenes, personas, reduced motion, fixtures, transition frames, viewports, `concept-vs-build.png` and `motion-preview.gif`, all regenerated by `python3 tools/captures.py`. The behaviour report is `captures/qa-report.txt` (26/26 pass). |

## Preview

```bash
cd apps/parlance/rive
rive .                                   # live previewer (window at 390x844)
python3 tools/fixture.py fixtures/extreme.json         # previewer with a fixture applied (--data)
python3 tools/fixture.py fixtures/zero-user.json --screenshot=out.png --advance=150
tools/shot.sh 9 out.png --data=personaIndex=3          # headless: navigate to scene 9 and capture
tools/trans.sh 3 40 out.png next                       # headless: frame 40 of the 3->4 handoff
python3 tools/qa.py                                    # behaviour checks -> captures/qa-report.txt
python3 tools/captures.py                              # rebuild every capture (+ concept side-by-side, gif)
/usr/bin/python3 tools/grain.py                        # regenerate assets/images/grain.png (needs Pillow)
```

**Host fit:** the master artboard is a fixed 390×844 design frame. Present it with `Fit.contain` centred, and fill the letterbox with paper `#FFF8EC` or a neutral colour. Captures at 320×568, 430×932 and 1280×800 (a centred desktop presentation) are in `captures/viewports/`. At 320×568 the frame scales to 67%, and there is no separate compact layout (see limitations). All content sits in a fixed `Stage` layout box, so a `Fit.layout` host crops instead of reflowing.

## Structure

- **Artboard `Parlance Recap`** (main, 390×844). From top to bottom of the hierarchy: chrome (wordmark, year, progress row, a `Controls` focus scope holding 5 buttons, the nav hit regions), the mouth hit target, the `Dwell Clock` placement, the hero-reveal driver, the quote aperture (the clip source shared by every scene), the **persistent motif** (`Motif A` is a persimmon comma-tailed speech form and `Motif B` a lilac one, each with a laughing face and an all-cubic, morphable body), then `Scene 10` … `Scene 1`, and under them the `Transition plate` (the colour seen around the opening/closing quote). Each scene node holds a grain overlay, its copy, foreground, mid and background art. All art is layered editable vectors (PointsPath, parametric shapes and font glyphs); the only raster is one 29 KB paper-grain tile (`assets/images/grain.png`) drawn with the overlay blend.
- **Component `Dwell Clock`** (nested). It owns the auto-advance timer. Its speed is bound to `1/clamp(autoAdvanceSeconds, 4, 60)` and its `isPaused` to `UserRecap.isPaused`.
- **Component `Share Card`** (nested, 342×556). This is the collectible summary card: wordmark, year, persona emblem, title and the five aggregate tiles. It has its own state machine (assembly, privacy flags, persona pick, new-user mode). It has no chrome, so a host can render it alone for the share snapshot.
- **State machine `Recap`** has these layers:
  - `Sequence`: about 110 states. Per scene there are forward and back gates, In, Back-In, Reduced-motion-In, Dwell, Out, Out-Back and reduced-motion fades, plus carry gates.
  - `Idle loops`
  - `Persona` and `Persona idle`
  - `Chrome theme`
  - `Controls mode`
  - `Pause icon`
  - 8 × `Segment k visibility`
  - `Summary copy`
  - `Press (tap vs hold)`
  - `Mouth tap`

## Single global view model `UserRecap`

There is exactly one view model, `UserRecap`. Every scene, the nested Clock and Share Card, the summary, the progress row and the persona visuals bind to the same instance. The nested artboards inherit the root's data context. **Rive-specific note:** I bound `UserRecap` to the main artboard and did not use Rive's `viewModelType="global"`. The reason: a Rive *global* VM has a single instance and cannot be reached by `--data`/instance selection, which would make fixtures and host instance swapping impossible. Functionally it is still one shared instance. Exported instances: `Sample fixture` (default), `New user fixture`, `Extreme fixture`.

All contract properties from the brief exist with these names and types. Colour strings are `ViewModelPropertyColor` (ARGB): the adapter maps `#RRGGBB` to `FFRRGGBB`.

**Ownership**
- *Host writes:* user data, the `showScreenN` flags, labels and localized copy, `locale`, `autoAdvanceSeconds`, `autoAdvanceEnabled`, `isPaused` (also on app background or while sharing), `reducedMotion`, `soundEnabled`, the `share*` flags, `personaIndex`.
- *File writes (host reads):* `currentScreen` (canonical 1–10), `screenProgress` (0–1 dwell, written by the Clock), and `personaName`, `personaDescription`, `personaColor`. The file derives these three atomically from `personaIndex`; unknown or non-integer indices fall back to row 0.
- *The file also writes `isPaused`* on Pause/Play, Space, and hold-to-pause.

**Adapter additions (not in the brief's table)**

| name | type | purpose |
|---|---|---|
| `groupSeparator` | string | locale digit-group separator (`,` for en-GB, `.` for de, ` ` for fr). The file groups digits itself. |
| `personaName0..3`, `personaDescription0..3` | string | localized persona table. The Persona layer copies the row for `personaIndex` into `personaName`/`personaDescription` and writes `personaColor`, all in one state entry, so the label, palette and emblem never disagree. |
| `goNext`, `goPrevious`, `requestReplay` | trigger | host-callable navigation (the same triggers the buttons, keys and taps fire). |
| `_dwellStart`, `_dwellStop`, `_heroReveal`, `_focusIndex`, `_pointerDown`, `_pressSide`, `_finishedLatch`, `_mouthTap`, `_focusVisible` | internal | animation playheads and latches. The underscore marks them private, and hosts should not write them. |

**Formatting:** counts are clamped with `max(0, round(x))` in converters. Three tiers (<1,000, <1,000,000, larger) build `1,860` or `1,234,567` from `groupSeparator`, and `fitFontSize` handles extreme widths without compacting. Hero numbers count from 0 to the value through the bound `_heroReveal` driver, so no placeholder digits flash. **The host adapter must:** clamp NaN/∞ (converters can't), choose singular or plural unit strings (`screenNUnit`), compose the localized `introHeadline`/`periodLabel` from year and name, and provide accessible full-value text and announcements. `tools/fixture.py` is a reference adapter for previews.

**Events**
- `screenChanged`: fires on every scene entry. Its payload is the custom property `screen`, bound to `currentScreen`. Read `currentScreen` as the source of truth.
- `shareTapped`: fires from the Share button or Enter. The host owns the capture and the platform share sheet. Only the event wiring is supplied; there is no real share integration. Set `isPaused=true` while the sheet is open and restore the previous value afterwards.
- `recapFinished`: fires once, the first time the summary settles. Replay clears the latch.
- `mouthTapped`: fires on the signature interaction. Its payload is `soundEnabled`. The file is silent; if `soundEnabled` is true, the host may play an opt-in sound.

The headless CLI does not report plain events. `qa.py` therefore verifies the state each firing state writes, and confirms that the events exist in the `.riv`.

## Behaviour (all verified in `captures/qa-report.txt`)

- **Navigation:** the right two-thirds of the story area advances and the left third goes back. Holding pauses (350 ms threshold), and releasing resumes without a tap. Previous, Pause/Play and Continue have 52 pt targets; the summary shows Replay and Share. Left/Right navigate and Space pauses. Tab and Shift+Tab move focus (a persimmon ring shows it), and Enter activates the focused button. Buttons carry `SemanticData` labels bound to the label strings.
- **Hidden scenes:** skipped in both directions. The progress row is a flex row with `display:none` per hidden segment, so exactly the visible count renders. Intro and summary are always eligible, whatever their flags say. With no eligible metric scenes, the flow goes intro → welcoming summary (`emptyHeadline`) with a neutral motif and no persona.
- **Auto-advance:** 7 s by default, counted after the entrance settles and clamped to at least 4 s. `autoAdvanceEnabled=false` holds the current scene. Pause freezes the timer, the idle loops and the persona idle while keeping progress. The summary never auto-loops.
- **Rapid taps:** a tap during an entrance skips straight to the next scene, and a tap during an exit skips one further (entrances cut in; no cross-blend). Five quick taps from scene 1 land on scene 6, and no scene is entered twice.
- **Reduced motion:** every arrival uses the scene's final pose, a 200 ms fade and no camera or motif movement. The idle loops are frozen and every control still works.
- **Privacy:** the card hides the name unless `shareIncludeName` is set. `practiceMinutes` is treated as the one sensitive aggregate and shows "—" unless `shareIncludeSensitiveValues` is set. No recordings, transcripts or locations appear anywhere.

## Motion

Timings are at 60 fps.

- Scene entrances follow the score: 0–200 ms is the quote aperture's dots → quotation mark (the anticipatory gesture), 200–1,400 ms is the hero and count, then the copy resolves word by word by about 1.8 s, then a restrained idle runs.
- Handoffs are 450–850 ms (generic forward 467 ms, signature 733 ms, reverse 500 ms). The reverse direction is the signature played backwards: the scene closes into a quotation mark, then the lilac form deflates, with a compressed rebuild.

**Hero sequences**
1. Intro: the cover collapses into the motif pair, and the wordmark letters stretch out of an envelope (text modifier).
2. Scene 3: an elastic mouth opens around the rolling numerals.
3. Scene 4: multilingual word blocks cascade into giant quotation marks.
4. Scene 9: the persona reveal. The motif pair orbits and winds up, then collapses into the emblem. Each persona has its own emblem silhouette and choreography: welcoming faces with speech marks, a stacked quotation-mark archive, an open-parenthesis ear with sound ripples, and an elastic exclamation mark with squash and stretch.
5. Scene 10: the summary card assembles.

**Continuity carries**
- 1→2: the two speech forms travel down into the conversation.
- 2→3: the persimmon form flies to centre stage, and its mouth becomes scene 3's mouth.

**Signature transition:** a speech form elongates (true vertex morph) until it fills the frame, then the next scene opens through a quote-shaped aperture (two dots sprout comma tails, then the quote opens). 3→4 is the hero version, where scene 3's lips morph into the speech bubble first; 4→5 … 9→10 use the motif forms. The reverse closes the scene into a quotation mark and the lilac form deflates. Details under "Refinement pass".

**Signature interaction:** tapping the illustrated mouth in scene 3 or 2 plays a silent elastic squash. Its opaque hit target cancels the story tap, so it cannot navigate.

## Measurements

These come from the CLI on this Mac. The headless renderer is not a phone, so treat the numbers as indicative.

- `.riv`: **1,982,450 bytes** (was 1,629,196 before the refinement pass). About 1.4 MB is fonts; most of the +353 KB is keyframes (the vertex morphs key 6 properties × 10 vertices per form, and every cubic key carries its own interpolator), plus 29 KB grain and 5 KB CJK subset.
- `rive . --bench=600` (scene 1, 390×844 @1x): advance mean 0.063 ms (p95 0.46 ms), render mean 0.145 ms (p95 0.15 ms; one 24 ms first-frame outlier). Before: 0.032 / 0.060 ms. Still far under the 16.7 ms budget for 60 fps. No measurement was taken on a real device.
- Objects: main artboard 54,681 (was 17,637; ~24k are keyframes), Share Card 2,321. Particle and token pools stay bounded at 7–15 objects per scene, so nothing scales with a raw count.

## Unsupported or substituted techniques (honest list)

- **Global VM:** uses one shared bound instance rather than Rive's `global` type (see above).
- **Locale formatting:** there is no locale-aware converter, so the file groups digits from the host's `groupSeparator`. Plurals and decimals beyond integers are the adapter's job.
- **Dwell timing:** an `AnimationState` cannot bind its speed, so the dwell timer is a nested artboard whose bindable `speed` scales a 1 s timeline. The timeline writes `screenProgress` and fires `goNext`.
- **State-machine writes:** a state machine can't write a VM number from a timeline, so animated drivers use two-way binds (`_heroReveal` on a hidden node's `x`, `screenProgress` on the Clock driver).
- **Morphs:** the motif forms, the scene-3 lips and the quote aperture now morph for real: every vertex (position and both handles) is keyed between same-count all-cubic paths (lips → bubble → elongated cover; dot → comma). Other secondary motion still uses node squash/stretch, TrimPath reveals, text modifiers and `TextFollowPathModifier` (scene 6 ribbons). No bones/meshes were needed.
- **Texture:** the concept's tactile rendering is approximated with gradient + inner-shadow (`Feather inner`) paints on each form, feathered highlights and ground pools, and one overlay-blended raster grain tile per scene. The grain sits above the art and copy but the overlay blend leaves near-white and near-plum (i.e. the type) almost untouched.
- **Audio:** no audio asset is shipped. The sound is opt-in and host-played via `mouthTapped`.

## Remaining limitations

- No `.rev` export yet (needs `rive login`).
- The file has not been opened in the editor or on a device, so frame rate there is unmeasured.
- 320×568 is a scaled (67%) presentation, not a bespoke compact layout.
- Long copy no longer reaches the illustrations: units are one fitted line, headlines a fitted box of at most three lines, captions sit on the control bar, intro/summary copy is bounded. The cost is that `extreme.json` headlines render smaller (about 30 px instead of 39).
- RTL was not verified (no RTL locale required).
- (Fixed) The focus ring is now a `:focus-visible` ring: `_focusVisible` is set by Tab / Shift+Tab and cleared by any pointer press, so pointer users no longer see a permanent ring on Continue.
- `screenChanged`'s `screen` payload is bound at fire time, so read `currentScreen`.
- The scene-6 weave is faked with a trimmed overlay segment.
- Plain events are not observable headlessly, so verify them in a host.

## Refinement pass (concept match + motion)

Goal: match `concept.png` (screens 2, 4, 9) more closely, carry that art direction through all ten scenes, and push the motion from "works" to kinetic typography. The contract (one `UserRecap` VM, property names, events, ten scenes, four personas, privacy flags, reduced motion, hidden-scene skipping, fixtures, Right-arrow navigation, 390×844) is unchanged, and `tools/qa.py` still passes 26/26 without edits. `captures/concept-vs-build.png` puts each concept screen next to the settled build scene.

### Concept gaps found (before) and what changed

| Gap (before) | Now |
|---|---|
| Numeral, unit and headline loosely spaced; headline 24–34 px; support line between headline and art | One type system for every metric scene (`top_copy` + `caption`): 138 px heavy numeral (wdth 100, −5 tracking), 27 px unit tight underneath, 39 px / 41 headline (wght 800, −0.6 tracking), support moved to a caption on the control bar |
| Round blob bubbles with small cute faces and an offset "depth" copy | Comma-tailed speech forms (round head, tail sweeping down like the concept's), big laughing D-mouths with a paper teeth band, closed arc eyes, gradient + inner-shadow shading, feathered highlight; no depth copies |
| Screen 2: bubbles low behind the controls, tokens only visible mid-flight | Persimmon form bleeding off the left, lilac off the right, tails converging; a settled cascade of eight punctuation tokens (+ dashes, three travellers) between the mouths; soft lemon/lilac pools |
| Screen 4: banana-shaped quotes, words scattered over the copy, Latin-only | Flat-topped block quotes at the bottom with dark pools; words, blank blocks and diamond confetti cascade diagonally from the upper right into the quotes, including ありがとう and 안녕 (5 KB CJK subset); a slow pour of tiny blocks keeps falling in |
| Screen 9: small pair of bubbles under quote marks on a flat halo | Two laughing speech forms hug a plum globe with drifting lemon land (clipped, seamless spin), swirl rings that draw on, sparkles and emphasis strokes; personas 1–3 rebuilt at the same scale on the same ring/sparkle/ground base (ring colours keyed per persona) |
| Flat colour everywhere | Gradient + inner shadow on every form, feathered highlights/pools, one overlay-blended grain tile per scene |
| Wordmark `parlance●` | `Parlance` title case, as in the concept (chrome and share card) |
| Focus ring always visible on Continue | `:focus-visible` behaviour (see limitations) |
| Persimmon progress on light, lemon on dark | Persimmon on both, lilac tracks on dark (concept screen 4) |

Carried into the other screens: scenes 5, 6 and 8 use the same top block (right-aligned on 5, centred on 8); scene 3 and 7 keep their inverted compositions but use the same type sizes; sparkles, pools and shading appear throughout; the summary card uses the new wordmark, typography and the full persona emblem with its rings.

### Animation improvements

- **Signature transition, rebuilt.** Forward: a speech form swings in, gathers into a squash (anticipation), then its body and tail *elongate by vertex morph* until it fills the frame (467 ms). The next scene then opens through the shared quote aperture: two dots sprout comma tails (a 9-vertex dot → comma morph), the quotation mark opens with an accelerating scale, and a bloom closes the gaps (≈570 ms, overlapping the entrance). The bubble colour alternates (persimmon/lilac) so it always contrasts with the next background, and the mark alternates between opening and closing quotes.
- **Hero version 3→4:** the lips purse, the mouth closes, the lips *morph into the speech-bubble silhouette*, which elongates to fill the frame, then scene 4 opens through the quotation mark onto its giant quotes (733 ms).
- **Designed reverse:** the current scene is clipped by the aperture as it *closes* into a quotation mark, whose tails retract into dots that blink out (500 ms, lilac plate); the lilac form that now fills the frame then deflates (tall → squash → rest morph) down-left while the previous scene rebuilds.
- **Kinetic typography:** headlines cascade word by word (rise + slight rotation, with an overshoot curve on the modifier range so each word passes its rest and settles); units type on letter by letter; support captions resolve by word; the persona title pops per letter with a squash-and-stretch overshoot; numerals start condensed (wdth 75) and stretch out to full width as the count lands.
- **Continuity carries** keep their roles and gain secondary motion: the 1→2 forms stretch while travelling and land with a squash morph; 2→3 now fades through the mouth faster.
- **Scene choreography:** scene 2's marks are spat out of the persimmon mouth along arcs and settle into the cascade; scene 4's words fall along the diagonal with tilt overshoot and the quotes drop, stretch and squash to catch them; persona reveal adds the ring burst (rings draw on, sparkles spin in) at the moment the orbiting pair collapses, with a globe that spins into place.
- **Summary assembly:** the card is thrown up, overshoots and lands with a squash; inside it the wordmark slides in, the year lands like a stamp, the emblem drops and squashes while its rings draw on, the title cascades, and the five tiles are dealt in from alternating sides with tilt, counting up from 0 with the hero driver; the motif tile flips in last.
- **Rapid navigation:** the 150 ms cross-blend into entrances was removed (it mixed the plate/clip states into a muddy frame); taps still step one scene per tap and settle on the last requested scene.

### New compromises

- `.riv` grew from 1.63 MB to 1.98 MB, mostly morph keyframes (see Measurements).
- The grain is a raster overlay above each scene's copy; the overlay blend keeps type crisp, but it is not vector.
- The globe's land is abstract blobs, deliberately not a real map (no regions or nationalities).
- Long localized headlines shrink (fit) rather than grow; extreme copy is legible but smaller.
- The persona swirl is three trimmed ellipse rings, not the concept's twisted ribbon.
- Still no Luau scripts or shaders: grain, shading and morphs are all native RML, so web hosts do not need `--publish`.
