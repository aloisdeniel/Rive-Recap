# Rive-Recap

Ten fictional apps exploring distinct visual styles for personalized, ten-screen Rive recaps.

Browse the [app gallery and implementation prompts](apps/README.md). Each app has a three-screen concept illustration, a complete motion-design brief, the image-generation prompt, and sample runtime data.

Start from [PROMPT_TEMPLATE.md](PROMPT_TEMPLATE.md) to write another recap brief. The app packages are concepts ready for implementation, not finished Rive exports.
